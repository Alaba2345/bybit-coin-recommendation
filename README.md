# Bybit Coin Recommendation Dashboard

Live crypto trading recommendation system with technical analysis.

## Quick Start

```bash
npm install
npm run dev
```

Open: http://localhost:5173

## Features
- Real-time Bybit market data
- RSI, MACD, Bollinger Bands indicators
- Buy/Sell signals with confidence scores
- Stop Loss & Take Profit levels
- Interactive price charts
- Mobile responsive design

## Build

```bash
npm run build
```

## Deployment

Connected to Vercel - auto-deploys on push to main branch.

https://bybit-coin-recommendation.vercel.app
